## ⚠️ Найденная проблема

**Баг:** Базовый алгоритм возвращает `NaN` для некоторых конфигураций фиксированных вершин.

**Пример проблемы:**
```
3 3 2
1 2
2 3
3 1
1 0.0 0.0
2 100.0 0.0
```

**Команда для воспроизведения:**
```bash
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  solve --input test_data/triangle_2fixed.txt --algorithm basic --output out.json
```

**Ошибка:** `System.Text.Json` не может сериализовать NaN.

**Рабочее окружение:** Используйте эвристический алгоритм для этого случая.

## Рекомендации

1. **Используйте базовый алгоритм** - он быстрее и точнее
2. **Избегайте конфигураций с NaN** - пока баг не исправлён
3. **Для визуализации** - используйте графы <100 вершин
4. **Для больших графов** - используйте флаг `--no-viz`
