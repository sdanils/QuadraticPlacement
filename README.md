# Quadratic Placement - Система квадратичного размещения элементов

Система для решения задачи размещения элементов с минимизацией взвешенной суммы квадратов длин связей. Реализует два алгоритма размещения с генерацией отчётов и визуализацией результатов.

## 📋 Описание задачи

**Задача квадратичного размещения** заключается в определении оптимальных координат вершин графа на плоскости таким образом, чтобы минимизировать суммарную длину всех рёбер при сохранении связности.

**Входные данные:**
- Граф с N вершинами и M рёбрами
- F фиксированных вершин с заданными координатами
- Веса рёбер

**Цель:** Разместить свободные вершины так, чтобы минимизировать взвешенную сумму длин рёбер.

## 🧮 Алгоритмы

### 1. Базовый алгоритм (матрица Лапласа)

**Принцип:** Решает систему линейных уравнений Lx = b, где L — матрица Лапласа графа.

**Особенности:**
- Точное решение системы линейных уравнений
- Использует разреженные матрицы (CSR формат)
- Метод сопряжённых градиентов для больших систем
- Раздельное решение для X и Y координат
- Учитывает фиксированные вершины через редукцию системы

**Преимущества:**
- ✅ Высокая точность
- ✅ Быстрая сходимость
- ✅ Эффективен для больших графов (10K+ вершин)
- ✅ Оптимальное решение для квадратичной целевой функции

**Сложность:** O(N²) на построение матрицы, O(N·√κ·log ε) на решение (κ — число обусловленности)

### 2. Эвристический алгоритм (силовой метод)

**Принцип:** Имитирует физическую систему с пружинами и силами отталкивания.

**Особенности:**
- Итеративный метод с имитацией отжига
- Силы притяжения вдоль рёбер (пружины Хука)
- Силы отталкивания между всеми парами вершин
- Адаптивное число итераций в зависимости от размера графа
- Ранняя остановка при стагнации

**Параметры:**
- Максимальное число итераций: 100 (для графов >1000 вершин)
- Начальная температура: 100.0
- Коэффициент охлаждения: 0.95
- Константа пружины: 1.0
- Идеальная длина пружины: 50.0
- Константа отталкивания: 1000.0

**Преимущества:**
- ✅ Простота реализации
- ✅ Визуальная интерпретируемость
- ✅ Гибкость настройки параметров

**Недостатки:**
- ❌ Медленная сходимость (O(iterations × edges))
- ❌ Локальные оптимумы
- ❌ Плохо масштабируется на большие графы

## 📊 Метрики качества

Система вычисляет следующие метрики:

- **Суммарная взвешенная длина** — основная метрика качества
- **Максимальная длина ребра** — самый длинный проводник
- **Минимальная длина ребра** — самый короткий проводник
- **Средняя длина ребра** — усреднённая длина
- **Время вычисления** — производительность алгоритма

## 🚀 Установка и запуск

### Требования

- .NET 8 SDK (уже включён в проект в `.dotnet/`)
- Linux/macOS/Windows

### Установка

```bash
# Клонирование репозитория (если необходимо)
git clone <repository-url>
cd integration_scheme

# .NET SDK уже установлен в .dotnet/
# Используйте обёртку: ./dotnet
```

### Команды CLI

#### 1. Генерация тестового графа

```bash
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  generate --output graph.txt --vertices 100 --edges 500 --fixed 10 --format text
```

**Параметры:**
- `--output`: имя выходного файла
- `--vertices`: количество вершин
- `--edges`: количество рёбер
- `--fixed`: количество фиксированных вершин
- `--format`: `text` или `json`

#### 2. Конвертация формата

```bash
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  convert --input graph.txt --output graph.json --to-format json
```

#### 3. Решение задачи размещения

```bash
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  solve --input graph.txt --algorithm basic --output result.json
```

**Параметры:**
- `--algorithm`: `basic` или `heuristic`

#### 4. Генерация сравнительного отчёта

```bash
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  report --input graph.txt --output report.html
```

**Опции:**
- `--no-viz`: пропустить генерацию визуализаций (быстрее для больших графов)

## 📖 Формат входных данных

### Текстовый формат

```
<вершин> <рёбер> <фиксированных>
u1 v1
u2 v2
...
idx1 x1 y1
idx2 x2 y2
...
```

**Пример:**
```
3 3 2
1 2
2 3
3 1
1 0.0 0.0
2 1.0 0.0
```

### JSON формат

```json
{
  "vertexCount": 3,
  "edges": [
    {"from": 1, "to": 2, "weight": 1.0},
    {"from": 2, "to": 3, "weight": 1.0},
    {"from": 3, "to": 1, "weight": 1.0}
  ],
  "fixedVertices": [
    {"index": 1, "x": 0.0, "y": 0.0},
    {"index": 2, "x": 1.0, "y": 0.0}
  ]
}
```
