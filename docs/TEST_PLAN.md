# Тестовый план системы квадратичного размещения

## Обзор

Документ описывает стратегию тестирования системы квадратичного размещения элементов, включая модульное, интеграционное и нагрузочное тестирование.

## Цели тестирования

1. Проверка корректности работы обоих алгоритмов (базовый и эвристический)
2. Сравнение производительности алгоритмов на графах разного размера
3. Проверка граничных случаев и обработки ошибок
4. Проверка работы модулей генерации, парсинга и визуализации

## Тестовые данные

## Тестовые сценарии

### 1. Модульное тестирование

Покрытие модулями тестами:

- **Core**: Graph, Edge, FixedVertex, Metrics, Exceptions
- **Data**: TextGraphParser, JsonGraphParser, GraphGenerator, GraphFormatConverter
- **Algorithms**: BasicSolver, HeuristicSolver, ConjugateGradientSolver

Команда для запуска:
```bash
./dotnet test tests/QuadraticPlacement.Tests/QuadraticPlacement.Tests.csproj
```

Текущий статус: **28 тестов, все проходят** ✓

### 2. Функциональное тестирование

#### 2.1. Генерация графов

```bash
# Малый граф
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  generate --output small.txt --vertices 50 --edges 100 --fixed 5 --format text

# Большой граф
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  generate --output large.txt --vertices 10000 --edges 50000 --fixed 500 --format text
```

Проверки:
- ✓ Файл создаётся в директории с временной меткой
- ✓ Формат соответствует спецификации
- ✓ Количество вершин/рёбер/фиксированных совпадает

#### 2.2. Парсинг входных данных

```bash
# Текстовый формат
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  convert --input graph.txt --output graph.json --to-format json

# JSON формат
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  convert --input graph.json --output graph.txt --to-format text
```

Проверки:
- ✓ Корректный парсинг валидных данных
- ✓ Обработка некорректных данных с информативными ошибками
- ✓ Круговая конвертация сохраняет данные

#### 2.3. Решение задачи размещения

```bash
# Базовый алгоритм
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  solve --input graph.txt --algorithm basic --output result.json

# Эвристический алгоритм
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  solve --input graph.txt --algorithm heuristic --output result.json
```

Проверки:
- ✓ Алгоритм завершается без ошибок
- ✓ Фиксированные вершины остаются на заданных позициях
- ✓ Свободные вершины получают координаты
- ✓ Метрики вычисляются корректно

#### 2.4. Генерация отчётов

```bash
# С визуализацией
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  report --input graph.txt --output report.html

# Без визуализации (для больших графов)
./dotnet run --project src/QuadraticPlacement.CLI/QuadraticPlacement.CLI.csproj -- \
  report --input graph.txt --output report.html --no-viz
```

Проверки:
- ✓ Создаются все три HTML файла
- ✓ Визуализация корректно отображает размещение
- ✓ Сравнительная таблица содержит корректные данные

## Known Issues

1. Эвристический алгоритм показывает худшее качество решения
2. Для графов >100K вершин возможно значительное увеличение времени работы эвристики
3. При большом количестве фиксированных вершин (>50%) возможно ухудшение качества решения
